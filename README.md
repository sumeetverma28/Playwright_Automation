# Playwright_Automation

Simple Playwright automation scripts. Run `Dashboard.py` or `Login_Program.py` from the project root.

Setup:

1. Install Python 3 and Playwright dependencies.
2. Install `git` and initialize the repository (see commands below).

Commands to finish and push to GitHub:

```bash
sudo apt update && sudo apt install -y git
cd /path/to/Playwright_Automation
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/<your-username>/<repo>.git
git push -u origin main
```
